# Landon Hotel Full-Stack Sample Application

A full-stack sample application built with a Spring Boot backend and an Angular frontend. This project demonstrates a hotel reservation system with room availability search, reservation creation, H2 persistence, REST APIs, and a simple UI.

## Project Structure

- `src/main/java`: Spring Boot backend code
  - `edu.wgu.d387_sample_code.rest`: REST controllers for booking and welcome/time endpoints
  - `edu.wgu.d387_sample_code.convertor`: request/response conversion logic
  - `edu.wgu.d387_sample_code.entity`: JPA entities for rooms and reservations
  - `edu.wgu.d387_sample_code.repository`: Spring Data repositories
  - `src/main/resources`: application configuration, H2 console settings, static UI assets
- `src/main/UI`: Angular frontend application
- `pom.xml`: Maven build configuration and dependencies

## Key Technologies

- Java 17
- Spring Boot 2.7.2
- Spring Data JPA
- H2 embedded database
- Angular 14
- Maven
- Node.js / npm

## Features

- Room availability search by check-in/check-out dates
- Reservation creation through REST API
- Simple welcome and time conversion endpoints
- H2 database persistence with console access
- Angular-based frontend in `src/main/UI`

## REST API Endpoints

- `GET /api/welcome`
  - Returns multilingual welcome messages generated by concurrent tasks.
- `GET /api/time-conversion`
  - Returns time conversion output from multiple time zones.
- `GET /room/reservation/v1?checkin={date}&checkout={date}`
  - Returns available rooms for the requested stay range.
- `GET /room/reservation/v1/{roomId}`
  - Returns room details for the given room ID.
- `POST /room/reservation/v1`
  - Creates a reservation from a JSON payload.

> Note: The API base path for room reservation operations is `/room/reservation/v1`.

## Getting Started

### 1. Build the Angular UI

```bash
cd src/main/UI
npm install
npm run build
```

### 2. Build the Spring Boot application

From the repository root:

```bash
mvn clean package
```

The Maven build includes the UI build step and packages the application into a runnable JAR.

### 3. Run the application

```bash
mvn spring-boot:run
```

Or run the packaged JAR directly:

```bash
java -jar target/D387_sample_code-0.0.2-SNAPSHOT.jar
```

### 4. Access the application

- Backend base URL: `http://localhost:8080`
- H2 console: `http://localhost:8080/h2-console`

The UI can be served from the built static resources if integrated with the backend, or run separately from `src/main/UI` using `npm start`.

## H2 Database

The application uses H2 with file persistence, configured in `src/main/resources/application.properties`:

- `spring.h2.console.enabled=true`
- `spring.h2.console.path=/h2-console`
- `spring.datasource.url=jdbc:h2:file:~/spring-boot-h2-d387F`

## Angular UI Development

To run the Angular development server independently:

```bash
cd src/main/UI
npm install
npm start
```

Then open the Angular app at `http://localhost:4200`.

## Notes

- The backend uses H2 for persistence and auto-creates or updates schema via Hibernate.
- Reservation update and delete endpoints are stubbed and may require further implementation.
